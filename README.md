# JejakDuit
Aplikasi pencatatan keuangan (PWA). Tanpa login dan tanpa backend: data tersimpan di browser (localStorage) pada perangkat masing-masing.

## Deploy ke Cloudflare Pages
Hubungkan repo GitHub. Build command dikosongkan, output directory `/`.

## Fitur
Beranda (catat cepat, budget, 7 hari), Transaksi (cari, filter, ubah, hapus), Laporan (donat, tren 6 bulan), Profil (6 palet, mode terang/gelap, mata uang, budget, ekspor/impor CSV).

## Catatan
- Data hanya ada di perangkat tempat dipakai. Jika data situs dihapus, data hilang. Cadangkan lewat Profil > Ekspor CSV.
- Perangkat berbeda tidak saling sinkron.
