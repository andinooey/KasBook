# Kasku
Aplikasi pencatatan keuangan (PWA). Tanpa login dan tanpa backend: data disimpan di browser (localStorage) pada perangkat masing-masing.

## Deploy ke Cloudflare Pages
Hubungkan repo GitHub. Build command dikosongkan, output directory `/`.

## Catatan
- Data hanya ada di browser/perangkat tempat dipakai. Jika data situs dihapus, data hilang. Cadangkan lewat Laporan > Ekspor CSV.
- Perangkat berbeda tidak saling sinkron.
